Перед запуском

Коротко о важном.

BesterLauncher — официальный лаунчер Minecraft?

Нет. Это независимый проект, не связанный с Mojang Studios или Microsoft.

Где скачать установщик?

Кнопка скачивания открывает GitHub Releases. Выбери последний доступный релиз и его Setup (.exe).

Нужна ли лицензия Minecraft?

Для Bedrock нужна лицензия Microsoft. Официальный вход в Minecraft Java выполняется через Microsoft.

Автообновление уже работает?

Код обновления готов, но публичный HTTPS-манифест пока не подключён. Пока устанавливай обновления вручную со страницы GitHub Releases.
